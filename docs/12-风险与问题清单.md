# 12 风险与问题清单

| 编号 | 风险 | 概率 | 影响 | 处置 |
| --- | --- | --- | --- | --- |
| R-01 | DeepSeek Key 错误 | 中 | 高 | 401 分类，不重试，显示安全提示 |
| R-02 | DeepSeek 余额不足 | 中 | 中 | 402 分类，停止调用 |
| R-03 | 超时、限流或上游错误 | 中 | 中 | 有限退避，仅未输出文本时重试 |
| R-04 | 演示范围外问题 | 中 | 中 | 说明数据范围，不编造字段事实 |

| R-08 | CSV 与汇总不同步 | 低 | 高 | 自动生成并对关键指标做校验 |
| R-09 | Windows Node 原生模块锁定 | 中 | 中 | 安装脚本先停止托管服务 |

| R-12 | 实现与文档脱节 | 中 | 中 | 发布前重建 Word 和追溯矩阵 |
| R-13 | API 真实调用产生费用 | 中 | 中 | 控制问题长度、超时、重试和使用预算 |

问题关闭记录需包含复现条件、影响、永久修复和验证证据。P0 未关闭不得发布。

## 2 风险登记细项

| 编号 | 触发信号 | 影响 | 预防 | 应急/回退 | 责任 |
| --- | --- | --- | --- | --- | --- |
| R-01 Key 错误 | HTTP 401 | AI 问数不可用 | 启动前设置环境变量并禁止打印 | 不重试，显示本地演示 | 后端 |
| R-02 余额不足 | HTTP 402 | AI 问数不可用和费用异常 | 控制测试频率，设置预算 | 停止请求，使用演示回答 | 项目负责人 |
| R-03 上游故障 | timeout/429/5xx | 流中断 | 请求限时、有限重试 | SSE error 后停止重放 | 后端 |
| R-04 敏感字段暴露 | Schema 包含身份、财务或客户字段 | 企业数据泄漏 | 显式遮蔽确认、最小化上下文 | 停止 Run，审查审计和密钥 | 数据/安全 |
| R-05 SQL 写入风险 | 模型计划包含非只读语句 | 业务数据被改 | AST 检查、只读连接和行数限制 | 拒绝执行并保留事件 | 后端 |
| R-06 数据口径错误 | CSV 和 summary 不一致 | 错误经营结论 | 自动汇总和校验脚本 | 撤回报告，重建 summary | 数据 |
| R-07 Node 原生包占用 | Windows EPERM/锁文件 | 一键安装失败 | 安装脚本先停止服务 | 清理本项目服务后重新安装 | 构建 |
| R-08 Docker 不可用 | Sandbox 启动失败 | 无 Python 文件产物 | 发布前验证 Docker 镜像 | SQL 结果照常使用，说明限制 | 运维 |
| R-09 文档过期 | 实现与 Word 内容不一致 | 评审误判 | 发布脚本重建 Word 并渲染 | 阻止文档发布 | 文档负责人 |
| R-10 屏幕过窄 | 视口小于断点 | 表格/图表难读 | 响应式和局部滚动 | 保留问数入口，横向滚动明细 | 前端 |

## 3 风险接受

P0 安全、数据损坏和服务启动风险不可接受，必须关闭。P1 可接受风险必须由项目负责人记录临时措施和关闭版本。演示数据的合成属性属于边界说明，不得被当作真实经营风险预测。
