# 智析 ChatBI V1.0 开发文档目录

本目录是 V1.0 的正式文档基线，按“需求分析优先、架构与设计继承需求、测试逐项追溯、验收形成结论”的顺序组织。每份编号 Markdown 都同步生成同名 Word，方便评审、版本比较和后续修改。

| 编号 | 文档 | 核心用途 |
| --- | --- | --- |
| 01 | 软件需求规格说明书 | 系统范围、角色、FR/NFR、接口、数据、安全、约束和验收 |
| 02 | 系统架构设计说明书 | 分层、组件边界、运行模式、部署和可靠性 |
| 03 | 功能设计说明书 | 模块、流程、状态、业务规则和逐功能验收 |
| 04 | UI UX 设计说明 | 视觉系统、响应式、动效、焦点和页面规范 |
| 05 | 详细设计说明书 | 前后端模块、DeepSeek、受控分析 Run 和资源管理 |
| 06 | 数据与接口设计说明书 | 字段字典、summary、HTTP、SSE 和状态码 |
| 07 | AI 技术方案说明书 | Responses API、Agent、SQL Gateway、DataLink、准确性和隐私 |
| 08 | 开发实施计划 | 工作包、阶段、职责和完成定义 |
| 09 | 测试计划与测试用例 | 测试范围、环境、用例、缺陷等级和退出条件 |
| 10 | 测试报告 | 执行环境、结果、数据核对、缺陷和发布结论 |
| 11 | 需求追溯矩阵 | FR/NFR/C 对应设计、代码、测试和状态 |
| 12 | 风险与问题清单 | 风险信号、影响、预防、应急和责任 |
| 13 | 系统使用说明及操作手册 | 启动、问数、数据源、模型、Run 和排错 |
| 14 | 编译构建指南 | uv/npm 锁定依赖、迁移、类型检查、构建 |
| 15 | 测试执行指南 | 前后端测试、DeepSeek 冒烟、健康和 Word 渲染 |
| 16 | 部署发布手册 | 环境变量、Windows/生产部署、监控、回滚 |
| 17 | 发布说明与验收清单 | V1.0 交付范围、发布检查和放行条件 |
| 18 | 版本变更记录 | 版本、日期、内容和基线状态 |

## 阅读顺序

产品、开发和测试首先阅读 01；架构和后端阅读 02、05、06、07；前端和设计阅读 03、04、05；测试阅读 01、09、10、11；演示与运维阅读 13、14、15、16、17。

## 文档规则

FR 表示功能需求，NFR 表示非功能需求，C 表示约束，TC 表示测试用例，R 表示风险。P0 是放行必需项，P1 是应完成能力，P2 是后续增强。任何需求变更需同步更新设计、测试和追溯矩阵。合成订单仅用于演示，不代表真实企业经营事实。
