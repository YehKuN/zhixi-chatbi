# 16 部署发布手册

## 1 部署组成

Web、FastAPI、DataLink、Metadata SQLite、Artifact 目录、演示数据和环境配置。开发端口为 Web 5280、主 API 8280、DataLink 8281。

## 2 环境变量

| 变量 | 必填 | 用途 |
| --- | --- | --- |
| SECRET_MASTER_KEY | 是 | 服务端加密模型凭据 |
| DEEPSEEK_API_KEY | 启用 DeepSeek 时 | 模型密钥，仅服务端读取 |
| DEEPSEEK_BASE_URL | 否 | 默认 https://api.deepseek.com |
| DEEPSEEK_MODEL | 否 | 默认 deepseek-flash |
| CORS_ORIGINS | 是 | Web 来源白名单 |
| DATASOURCE_ROOT | 是 | 数据源根目录 |
| ARTIFACT_ROOT | 是 | 分析产物根目录 |

## 3 Windows 启动

安装 Python 3.12 和 Node.js 22.12+；设置 DEEPSEEK_API_KEY；首次运行安装并启动智析ChatBI.bat；之后运行启动智析ChatBI.bat。健康检查通过后再开放评审使用。

## 4 生产要求

Web 和 API 使用 HTTPS 反向代理；FastAPI 单 worker；DataLink 仅内网；Key 使用环境变量或部署 Secret；storage 采用最小权限；备份 Metadata 和 Artifact。开发服务不能直接暴露公网。

## 5 监控和回滚

监控 API/DataLink 健康、401/402/429、Run failed、SSE 中断、磁盘、备份和模型费用。回滚时停止服务，备份当前数据，恢复上一版代码和锁文件，按迁移策略恢复数据库，启动后执行健康检查和问数冒烟。

## 6 安全清单

确认 .env、Key、真实企业数据、storage、.venv、.tmp 未进入交付包；CORS 最小化；日志脱敏；字段遮蔽和 SQL 只读边界有效。

## 7 数据备份

关闭写入后备份 storage/metadata.db 和 ARTIFACT_ROOT；保留 Alembic 当前 revision、代码 tag 和 uv/npm 锁文件。恢复后先运行迁移状态检查和 health，再允许业务访问。

## 8 日志和秘密

日志保留时间和访问权限由部署环境配置。严禁把 DEEPSEEK_API_KEY 写入批处理、启动参数、前端变量、issue 或截图。仅通过运行环境 Secret 注入；轮换密钥时重启 API 并以 401/200 安全验证。

## 9 网络策略

Browser 只连公开 Web/API；DataLink、Metadata 和 Artifact 不应面向公网开放。CORS 使用最小来源白名单；反向代理需关闭 SSE 缓冲并设置合理 read timeout。
