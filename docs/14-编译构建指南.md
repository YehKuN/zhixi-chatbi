# 14 编译构建指南

## 1 一键安装

首次运行“安装并启动智析ChatBI.bat”。脚本先停止本项目托管的旧服务，使用 Python 3.12 创建 .venv，根据 uv.lock 安装后端和开发依赖，根据 package-lock.json 安装前端依赖，准备本地环境、运行 Alembic 迁移并启动服务。

后续使用“启动智析ChatBI.bat”。停止和状态查看分别使用“停止智析ChatBI.bat”和“查看智析ChatBI状态.bat”。

## 2 手动安装

py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install uv
.venv\Scripts\uv.exe sync --locked --group dev
powershell.exe -ExecutionPolicy Bypass -File scripts\install-frontend.ps1
.venv\Scripts\python.exe -m tools.prepare_local
.venv\Scripts\python.exe -m alembic upgrade head

## 3 构建和测试

npm run typecheck
npm run build
npm run test
.venv\Scripts\ruff.exe check apps\api tools tests
.venv\Scripts\python.exe -m pytest
.venv\Scripts\python.exe tools\verify_deepseek.py

生产前端输出到 apps/web/dist。Web 5280、API 8280、DataLink 8281。DeepSeek Key 由启动进程环境变量提供；.env、storage、.venv、.tmp 不提交。

## 5 Node.js 选择和 Windows 原生依赖

前端构建使用 Vite 8，要求 Node.js 22.12 或更新版本。install-frontend.ps1 会逐个检查 PATH 中的 node.exe，并选择满足版本要求的程序；若 npm ci 没有安装 Windows 可选原生绑定，脚本补装锁定版本的 binding-windows 包。安装前要先停掉 Vite 服务，避免 DLL/PYD 锁定。

## 6 数据库初始化

安装并启动脚本会运行 Alembic upgrade head。迁移只创建或更新 Metadata schema，不会清理 storage。生产升级前先备份 Metadata SQLite 和 Artifact 文件目录。
