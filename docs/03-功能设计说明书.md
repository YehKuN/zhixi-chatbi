## 2 经营驾驶舱

### 2.1 信息结构

```text
侧栏：品牌 / 工作空间 / 分析空间导航 / 数据资源 / AI 引擎 / 用户
顶部：面包屑 / 实时状态 / 日期 / 刷新 / 提醒 / 导入数据
内容：页面标题 → 指标卡 → 营收趋势 + AI 洞察 → 问数 + 答案 → 收入来源 + 区域 TOP5 + 预警
```

### 2.2 指标卡

| 指标 | 口径 | 来源 |
| --- | --- | --- |
| 10 月截至 29 日订单金额 | 2026-10-01 至 10-29 的 `order_amount` 合计 | `latest_month.revenue` |
| 活跃客户 | 当月有订单的去重客户数 | `latest_month.active_customers` |
| 平均订单金额 | 当月订单金额 / 订单数 | `latest_month.avg_order_value` |
| 累计毛利率 | 累计毛利 / 累计订单金额 | `totals.gross_margin_pct` |

指标卡显示数值、环比变化、口径提示与“近 30 天”说明；不得硬编码第二套数字。

### 2.3 图表

| 图表 | 类型 | 数据 |
| --- | --- | --- |
| 营收趋势 | 双折线 | `months[].revenue`、`months[].gross_profit` |
| 收入来源 | 环图 | `latest_month.channels` |
| 区域 TOP5 | 横向柱状 | `latest_month.regions` |
| 经营预警 | 列表 | `totals.unpaid_order_count`、`totals.open_receivables`、`latest_month.gross_margin_pct`、`gross_profit_change_pct` |

图表支持 tooltip、图例点击、resize；卸载时 dispose。

### 2.4 状态

| 状态 | 触发 | 呈现 |
| --- | --- | --- |
| demo | 无真实数据源 | “演示 · 906 条订单” |
| ready | 数据源 ready + 模型激活 | 数据源名称 + LIVE |
| analyzing | 提交问题 | 脉冲、发送禁用 |
| success | 回答完成 | 答案卡 + 证据入口 |
| error | 请求失败 | 稳定提示 + 重试/降级 |

## 3 智能问数

### 3.1 输入规则

- 长度 1–2000 字符；去除首尾空白；空值、纯空白、超长阻止提交。
- Enter 提交，Shift+Enter 换行；分析期间发送按钮禁用。
- 推荐问题点击后填充并聚焦；输入框自适应高度。
- 新问题不覆盖未完成的上一条回答。

### 3.2 三条分析路径

| 路径 | 条件 | 行为 | 来源标签 |
| --- | --- | --- | --- |
| 真实 Run | 数据源 ready + 遮蔽确认 + 模型激活 | 创建 Session/Run，订阅事件，展示答案与证据 | 数据源名称 + Run |
| DeepSeek 演示 | 有 Key、无真实数据源 | 服务端聚合上下文，SSE 流式回答 | DeepSeek · 演示 |
| 本地降级 | 无 Key / API 不可用 | 确定性回答，保留报告导出 | 演示模式 |

### 3.3 答案卡

答案卡包含：问题、结论、来源、时间范围、限制、证据入口。真实 Run 的答案附引用编号；演示答案明确标注“演示”。分析中显示“ANALYZING”，完成后显示“AI INSIGHT”。

### 3.4 错误提示

| 错误 | 提示 | 行为 |
| --- | --- | --- |
| 401 | API Key 无效 | 不重试，提示检查服务端配置 |
| 402 | 账户余额不足 | 不重试，提示充值 |
| 超时 | 请求超时，正在重试 | 未输出时有限退避 |
| 429/5xx | 服务暂时不可用 | 退避重试 |
| 已输出后中断 | 回答中断，请重试 | 不重放 |
| API 不可用 | 已进入演示模式 | 本地确定性回答 |

## 4 受控分析工作台

### 4.1 布局

- 左：Session 列表、当前数据源、Run 历史。
- 中：答案正文、引用、材料、Artifact。
- 右：运行检查台（阶段、工具、SQL 审计、DataLink 消费、证据、Trace DAG）。

### 4.2 Session 与 Run

| 操作 | 说明 |
| --- | --- |
| 新建 Session | 选择已 ready 数据源 |
| 提交问题 | 创建 Run，返回 202 |
| 订阅事件 | SSE 增量投影 |
| 取消 | 写入取消登记，等待终态 |
| 回放 | 历史事件只读重建，不调用模型 |
| 删除 Session | 级联清理消息、Run、摘要 |

### 4.3 运行检查台

| 区域 | 内容 |
| --- | --- |
| 阶段 | Opening、Preparation、Protocol、Discovery、Analysis、Commit、Final Answer |
| 工具 | 工具名、状态、耗时、输入/输出摘要 |
| SQL 审计 | 原始/规范化 SQL、状态、拒绝码、行数、耗时 |
| DataLink | 版本、实体、字段、关系、置信度 |
| 产物 | 类型、大小、预览、下载 |
| 证据 | Claim、引用、材料、快照 |
| Trace DAG | 节点、边、折叠、详情 |

### 4.4 状态与异常

| 状态 | 呈现 |
| --- | --- |
| queued | 排队中 |
| running | 执行中，显示当前阶段 |
| succeeded | 已完成，答案与证据可查 |
| partial | 部分完成，标注缺口 |
| failed | 失败，显示安全错误与建议 |
| canceled | 已取消 |

## 5 数据资产与 DataLink

### 5.1 数据源接入

| 类型 | 方式 | 约束 |
| --- | --- | --- |
| CSV | 上传 | 扩展名、大小（默认 100MB）、受控目录 |
| SQLite | 上传 | 扩展名、大小、只读打开 |
| MySQL | 连接 | 主机、端口、库、用户、密码、SSL 选项 |

流程：上传/连接 → `checking` → `schema_ready` → 确认遮蔽 → `ready`。失败可重试；重启恢复中断检查。

### 5.2 Schema 展示

表、字段、类型、行数、主键、外键、关系；敏感字段标记；遮蔽字段在选择后从分析投影中移除。

### 5.3 DataLink 生命周期

| 阶段 | 操作 | 结果 |
| --- | --- | --- |
| 建图 | 读取 Schema，生成实体/属性/关系草稿 | 草稿图谱 |
| 修订 | 合并实体、修正映射、确认关系 | 修订版本 |
| 校验 | 结构、引用完整性、字段存在性 | findings |
| 发布 | 形成不可变 revision | 可用版本 |
| 检索 | MCP 按业务词召回 | 实体、字段、关系 |
| 消费 | Run 记录版本与命中项 | 可追溯 |

### 5.4 异常

| 异常 | 提示 | 行为 |
| --- | --- | --- |
| 文件过大 | 超过上传限制 | 拒绝上传 |
| 扩展名不支持 | 仅支持 CSV/SQLite | 拒绝 |
| 连接失败 | 检查主机/端口/账号 | 可重试 |
| Schema 失败 | 检查文件完整性 | 可重试 |
| 未确认遮蔽 | 请先确认字段遮蔽 | 阻止创建 Run |
| DataLink 不可用 | 语义增强不可用 | 降级为 Schema 浏览 |

## 6 模型设置

### 6.1 配置项

服务商、模型名、Base URL、API Key、温度、超时、上下文窗口、推理模式、最大输出 token。

### 6.2 流程

1. 新建配置，填写参数与 Key。
2. 保存后 Key 加密存储，详情只显示 `has_api_key`。
3. 点击“测试配置”，探测工具调用与流式能力。
4. 测试通过后激活；激活模型用于后续 Run。
5. 删除前提示影响；历史 Run 使用快照，不受影响。

### 6.3 安全

- Key 只在提交时传入服务端；不写入前端、日志、报告。
- 未测试模型不能激活。
- 模型切换不改变历史 Run 的模型快照。

## 7 洞察报告、台账与收支

### 7.1 洞察报告

| 字段 | 说明 |
| --- | --- |
| 问题 | 本次分析的问题 |
| 结论 | 结构化结论 |
| 来源 | 演示 / 真实 Run / DeepSeek |
| 时间范围 | 数据截止日 |
| 证据状态 | 已核验 / 部分 / 缺失 |
| 限制 | 缺字段、截断、未执行项 |
| 导出 | Markdown |

### 7.2 项目台账

项目名称、负责人、当前阶段、整体进度、预计交付、AI 进度洞察；V1.0 为演示记录，不写外部系统。

### 7.3 收支管理

净现金流、收入、成本、回款状态、分类、交易明细；金额口径可复算；演示数据不伪装为正式财务凭证。

## 8 状态与错误规范

| 类别 | 规范 |
| --- | --- |
| 颜色 | 成功绿、运行蓝紫、预警橙、失败红、演示中性 |
| 图标 | 每种状态同时有图标与文字，不只靠颜色 |
| 文案 | 说明原因 + 下一步，不显示堆栈与上游原始响应 |
| 焦点 | 所有交互可键盘聚焦，焦点轮廓可见 |
| 空状态 | 说明为什么为空 + 可执行按钮 |

## 9 业务规则

| 编号 | 规则 |
| --- | --- |
| BR-01 | 页面数字来自 summary JSON 或真实 Run 产物 |
| BR-02 | 同期比较使用相同截止日 |
| BR-03 | 缺漏斗字段不算转化率，缺成本字段不算毛利率 |
| BR-04 | 待回款只统计 `payment_status=待回款` |
| BR-05 | Key 缺失时显示演示模式，不显示密钥 |
| BR-06 | 真实 Run 失败不覆盖历史成功结果 |
| BR-07 | 报告必须标注来源 |
| BR-08 | 未确认遮蔽 / Schema 未就绪 / 模型未激活不得建 Run |
| BR-09 | 无证据数字不进入结论 |

## 10 验收要点

| 模块 | 验收 |
| --- | --- |
| 驾驶舱 | 指标与 summary 一致；图表无裁切；卸载释放实例 |
| 问数 | 输入规则生效；三条路径可用；来源标签正确 |
| 工作台 | Run 可创建、订阅、取消、回放；审计与产物可定位 |
| 数据资产 | 三种类型可接入；遮蔽确认生效；DataLink 可建图/发布 |
| 模型 | Key 不回显；未测试不能激活 |
| 报告 | 字段完整、可导出、来源明确 |
| 响应式 | 1280 / 768 / 390 可操作，无页面级横向溢出 |
