## 7 执行环境和可复现命令

- 前端：npm run typecheck、npm run build、npm run test。
- 后端：.venv 解释器、uv.lock 锁定依赖、pytest。
- DeepSeek：服务端环境变量 DEEPSEEK_API_KEY，运行 verify_deepseek.py。
- 服务：Web 5280、FastAPI 8280、DataLink 8281。
- 文档：LibreOffice 通过绝对安装路径渲染 PDF，再由 Poppler 生成 PNG。

测试期间前端 Vitest 40 个文件、282 项通过；后端 Pytest 772 项通过；新增 DeepSeek 客户端用例 6 项通过；前端类型检查和生产构建通过。DeepSeek 外部冒烟请求成功完成 SSE。测试包含一次真实模型调用，会产生 API 用量。

## 8 测试覆盖和限制

测试报告验证当前锁定代码和本机演示环境，不代替目标企业环境验收。没有执行真实 MySQL、目标组织权限、真实企业字段遮蔽审查或生产规模性能压测；这些必须在获得目标环境授权后另行记录。
