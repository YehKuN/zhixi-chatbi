# 15 测试执行指南

## 1 前端测试

npm run typecheck 执行 Vue/TypeScript 类型检查；npm run build 生成 apps/web/dist；npm run test 执行 Vitest。

## 2 后端测试

.venv\Scripts\ruff.exe check apps\api tools tests 执行静态检查；.venv\Scripts\python.exe -m pytest 执行全量后端测试。

## 3 DeepSeek 真实冒烟

设置 DEEPSEEK_API_KEY 并启动服务后运行：

    .venv\Scripts\python.exe tools\verify_deepseek.py

通过标准：HTTP 200；收到一个以上 delta；最终收到 done。真实冒烟会产生模型调用费用，不应作为默认 CI 测试。

## 4 健康检查

主 API /health 返回 healthy，metadata 和 datasource_root 为 ok，DataLink 为 ok；DataLink /health 返回 graph_database=ok、mcp_mounted=true；Web /workspace 返回 HTTP 200。

## 5 Word 渲染

运行 powershell -ExecutionPolicy Bypass -File tools\render_docs.ps1。每个 Word 应生成非空 PDF 和 page-1.png；检查中文字体、表格、代码块、页脚和分页。

## 6 用例执行记录

一次执行记录至少包含：用例编号、构建版本、测试数据版本、环境、执行者、开始/结束时间、步骤、实际值、证据路径、结果和缺陷编号。失败用例重测时保留首次结果和复测记录，不覆盖历史。

## 7 API 错误注入

无 Key 测试不发送外网请求；401/402 可通过构造 APIStatusError 做单测；timeout 使用 APITimeoutError；429/5xx 验证重试次数。真实模型冒烟只验证当前账户链路，不用于稳定性或性能承诺。

## 8 文档自动化检查

对 docs 中编号 Markdown 重新生成同名 Word；确认 Word 数量和编号集合一致；执行 render_docs.ps1；检查每份 PDF 页数、PNG 存在和文件非空；随机检查表格及代码块，同时以脚本核对全部页面数。
