# 09 测试计划与测试用例

## 1 测试目标与范围

验证需求、交互、数据一致性、DeepSeek 流式、受控分析 Run、演示降级、安全、响应式和发布脚本。测试范围包含前端、FastAPI、DataLink、SQLite、CSV 汇总、AI 异常、接口和 Word 文档。

## 2 测试环境

Windows 10/11；Python 3.12；Node.js 22.12+；Microsoft Edge；Web 5280；FastAPI 8280；DataLink 8281；DeepSeek deepseek-flash；906 条演示订单。

## 4 通过标准

P0 全部通过，P1 无阻断；真实 SSE 至少包含 delta 和 done；演示模式不依赖 Key；高风险缺陷关闭或有明确处理计划。
