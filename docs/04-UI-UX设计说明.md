# 04 UI UX 设计说明

| 项目 | 内容 |
| --- | --- |
| 文档版本 | V1.0.1 |
| 编制日期 | 2026-10-31 |
| 适用范围 | 驾驶舱、分析工作台、数据资产、模型设置 |
| 设计工具 | Vue 3 单文件组件 + CSS 变量 + ECharts |

## 1 设计目标

以“企业数据驾驶舱 + 可信分析工作台”为主视觉，降低业务用户的阅读与提问成本，让用户始终知道四件事：

1. 我在哪个模块；
2. 当前数据来自哪里、截止到哪天；
3. 分析正在进行、已完成还是失败；
4. 结论可信到什么程度、证据在哪里。

## 2 视觉系统

### 2.1 色彩 Token

| Token | 值 | 用途 |
| --- | --- | --- |
| `--background` | `#050607` | 页面背景（深海黑） |
| `--card` | `#15181d` | 面板 / 卡片 |
| `--secondary` | `#1d2128` | 次级面板 / 输入背景 |
| `--primary` | `#d94b32` | 主操作、品牌强调（朱砂橙） |
| `--foreground` | `#f2f4f7` | 主文本 |
| `--muted-foreground` | `#9ba4b2` | 次文本 |
| `--border` | `#2c333e` | 边框 |
| `--ring` | `#8292ff` | 焦点环、AI / 执行中 |
| `--success` | `#76b7a0` | 成功、已完成、质量通过 |
| `--warning` | `#d28a28` | 预警、待回款、风险 |
| `--running` | `#8292ff` | 运行中 |
| `--workspace-page` | `#050607` | 工作台背景 |
| `--workspace-surface` | `rgba(18,20,24,.94)` | 玻璃面板 |
| `--workspace-surface-inset` | `#0b0d10` | 内嵌区域 / 代码块 |

### 2.2 字体与层级

- 界面字体：`Inter, ui-sans-serif, system-ui, "Segoe UI", sans-serif`；中文回退到系统黑体。
- 数据与代码：`ui-monospace, SFMono-Regular, Consolas, monospace`。
- 层级：页面标题 28–30px / 600–750；面板标题 13–17px；正文 13–14px；辅助信息 10–11px；计量数字使用等宽字形。
- 数字优先：指标卡先显示数值，再显示变化与口径；金额以万元格式化，原值保留两位小数。

### 2.3 玻璃质感

- 面板使用半透明深色 + 1px 高光边框 + 大范围阴影 + `backdrop-filter: blur(26px) saturate(130%)`。
- 背景使用两处径向渐变光晕（蓝紫 / 橙红），随鼠标位置轻微移动，营造“观测台”氛围。
- 动效克制：hover 250–400ms 弹性曲线；页面进入短距离 translate + opacity；分析中只保留必要脉冲；`prefers-reduced-motion` 下禁用持续循环动画。

## 3 布局

### 3.1 驾驶舱

```text
┌──────────┬──────────────────────────────────────────────┐
│ 侧栏      │ 顶部：面包屑 / 实时 / 刷新 / 提醒 / 导入数据     │
│ 品牌      ├──────────────────────────────────────────────┤
│ 工作空间  │ 页面标题 + 日期范围                           │
│ 分析空间  │ 四张指标卡（订单金额 / 活跃客户 / 客单价 / 毛利率）│
│ 导航      │ 营收趋势（大）+ AI 智能洞察（小）               │
│ 数据资源  │ 问问你的数据（输入框 + 推荐问题 + 来源）         │
│ AI 引擎   │ 答案卡（结论 + 来源 + 证据入口）                 │
│ 用户      │ 收入来源环图 / 区域 TOP5 / 经营预警              │
└──────────┴──────────────────────────────────────────────┘
```

- 侧栏固定，内容区独立滚动；桌面 1360–1600 宽度为主要评审分辨率。
- 850px 以下侧栏收窄；680px 以下指标卡两列、分析面板单列、表格内部滚动。
- 问数输入框位于页面中部偏下，是视觉与交互的中心；进入分析态时出现脉冲与禁用发送。

### 3.2 分析工作台

采用“左会话 / 中答案 / 右检查台”三栏：

- 左：Session 列表、当前数据源、Run 历史。
- 中：答案正文、引用编号、材料查看、Artifact。
- 右：运行检查台（阶段、工具调用、SQL 审计、证据、Trace DAG）。

窄屏时右栏折叠为抽屉，保证答案正文优先。

### 3.3 数据资产 / 模型设置

左右分栏：左侧列表与新建入口，右侧详情、Schema、图谱、版本与校验。空状态给出明确的下一步按钮，而不是空白页。

## 4 交互规范

| 场景 | 规范 |
| --- | --- |
| 导航 | 当前项高亮 + 左侧强调条；切换不整页刷新 |
| 按钮 | hover / focus-visible / pressed 三态；危险操作二次确认 |
| 输入 | Enter 发送，Shift+Enter 换行；1–2000 字符；空值与超长阻止 |
| 分析中 | 发送禁用、显示脉冲、允许取消；不阻塞其他模块浏览 |
| 图表 | tooltip 含单位与时间范围；图例可点击；resize 不裁切 |
| 错误 | 稳定中文提示 + 下一步建议；不显示堆栈与上游原始响应 |
| 报告 | 结论、口径、来源、证据、限制五项齐全；导出 Markdown |
| 空状态 | 说明为什么为空、可以做什么、按钮在哪里 |

## 5 无障碍

- 所有交互元素使用 `button`、`a` 或带 `label` 的输入，不使用无语义 `div` 点击。
- 图表提供 `aria-label`；颜色之外同时使用图标与文字表达状态。
- 焦点轮廓不移除；键盘可完成导航、提问、查看证据与导出。
- 支持 1280 / 768 / 390；390 宽度无页面级横向溢出。
- `prefers-reduced-motion` 下关闭持续动画与鼠标光晕。

## 6 状态呈现

| 状态 | 颜色 | 图标 | 文案 |
| --- | --- | --- | --- |
| 演示 | 中性 | 数据库 / 标签 | “演示 · 906 条订单” |
| 就绪 | 绿 | 对勾 | “Schema 已就绪” |
| 分析中 | 蓝紫 | 脉冲 / 旋转 | “正在分析” |
| 成功 | 绿 | 对勾 | “已完成” |
| 部分完成 | 橙 | 感叹号 | “部分完成，存在缺口” |
| 失败 | 红 | 叉 | “失败，可重试” |
| 已取消 | 灰 | 停止 | “已取消” |

颜色不代表结论正确；证据状态必须用文字与引用编号呈现。

## 7 验收

- 1360×768、1280×800、768×1024、390×844 四档无布局破损。
- 图表无裁切、光晕不遮挡文本、Toast 不超出屏幕。
- 键盘 Tab 顺序合理；图表有 aria-label；减少动效时功能仍完整。
- 页面指标与 summary 对账一致；来源标签始终可见。
