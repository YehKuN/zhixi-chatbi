# 13 系统使用说明及操作手册

## 1 启动

1. 首次运行根目录“安装并启动智析ChatBI.bat”；后续运行“启动智析ChatBI.bat”。
2. 若启用 DeepSeek，在启动 shell 中设置 DEEPSEEK_API_KEY。
3. Web 地址为 http://127.0.0.1:5280/workspace。
4. 用“查看智析ChatBI状态.bat”检查服务；用“停止智析ChatBI.bat”关闭。

## 2 驾驶舱

左侧模块为经营驾驶舱、智能问数、洞察报告、项目台账、收支管理。指标显示 906 条演示订单汇总；趋势展示月度订单金额和毛利；渠道和区域图显示 10 月 1 日至 29 日构成；经营预警显示待回款笔数和毛利变化。

页面必须标记演示数据来源和截至日期。真实模式应显示真实数据源名称和 Schema 状态。

## 3 提问

1. 点击问数输入框或推荐问题。
2. 输入“截至 10 月 29 日，各区域订单金额和回款情况如何？”。
3. 点击发送或按 Enter。
4. 配置 DeepSeek 时回答会逐片显示；服务不可用时系统提示原因并使用演示降级。
5. 查看结论卡的数据来源、时间范围和限制。
6. 没有销售漏斗字段时不能计算客户转化率，应说明数据不足。

## 4 图表与报告

悬停图表查看 tooltip；查看收入来源、区域排名和趋势。进入“洞察报告”检查问题、结论、数据范围和证据状态，点击导出下载 Markdown 文件。

## 5 数据资产和模型

数据资产页支持 CSV、SQLite 和 MySQL 上传/连接。Schema 准备后检查字段并确认遮蔽清单。真实分析必须满足数据源 ready、遮蔽已确认和模型已激活。模型设置页可创建、测试和激活模型；API Key 只显示配置状态。

## 6 受控分析工作台

访问 /analysis 创建 Session，选择真实数据源后提交问题。在运行检查台查看阶段、事件、SQL 审计、DataLink 消费、Artifact 和证据引用。历史 Run 为只读回放。

## 7 常见错误

| 提示 | 处理 |
| --- | --- |
| API Key 无效 | 检查环境变量，不要把 Key 粘贴到聊天或截图 |
| DeepSeek 余额不足 | 检查账户余额后再重试 |
| 请求超时 | 检查网络，系统只进行有限重试 |
| 数据源未就绪 | 重新检查 Schema 和字段遮蔽 |
| 端口占用 | 使用状态脚本确认服务状态，不强制关闭未知进程 |

## 8 退出

使用停止智析ChatBI.bat。该操作关闭本项目托管服务，不删除 storage、数据库或文档。

## 9 完整问数示例

问题：截至 10 月 29 日，各区域订单金额和回款情况如何？

操作：提交问题；等待 DeepSeek delta；检查回答中的日期、单位、区域和回款范围；如需验证，打开数据汇总或 /analysis 查看真实 Run 证据。演示数据答案不得扩展到 CSV 没有的客户转化率、合同条款或外部业务事实。

## 10 模型配置步骤

1. 打开模型设置并新增兼容模型。
2. 填写模型标识、服务地址、超时和 API Key。
3. 保存后点击测试配置。
4. 工具调用能力通过后再激活。
5. 确认详情页只有密钥状态而没有密钥文本。

## 11 数据源准备步骤

1. 选择 CSV/SQLite/MySQL。
2. 上传文件或输入连接信息。
3. 等待 Schema 状态结束。
4. 阅读字段目录和敏感字段。
5. 保存明确的遮蔽字段确认。
6. 创建真实会话并选择此数据源。

## 12 故障处理

若启动失败先查看 .tmp/logs；若 8280/8281/5280 端口冲突运行状态脚本，勿结束未知进程；DeepSeek 401 检查环境变量值是否有效，402 检查余额，网络超时检查外网；数据源失败检查文件权限和 Schema。
